# NYC Motor Vehicle Crashes — Exploratory Data Analysis

## Project Overview
This project analyzes **motor vehicle crash data across New York City** using publicly available data from **NYC OpenData**, provided by the **New York Police Department (NYPD)**.  
The dataset spans **2012–2024** and contains **over 2 million crash records**.

The objective of this analysis is to explore crash trends over time, identify temporal and spatial patterns, and evaluate whether major events such as **COVID-19** significantly impacted accident behavior.

---

## Dataset
- **Source:** NYC OpenData [NYPD Motor Vehicle Collisions](https://data.cityofnewyork.us/Public-Safety/Motor-Vehicle-Collisions-Crashes/h9gi-nx95/about_data)
- **Time Period:** 2012–2024
- **Size:** 2+ million rows
- **Granularity:** Incident-level crash data (date, time, location, contributing factors)

---

## Project Milestones
The project was completed across five key milestones:

1. **Data Preparation**
   - Data ingestion and schema understanding  
   - Initial quality checks  

2. **Data Ethics, Pre-Processing, & Exploration**
   - Handling missing values  
   - Data cleaning and transformations  
   - Ethical considerations of public safety data  

3. **Time Series Analysis**
   - Crash trends across years  
   - Seasonal and daily patterns  
   - Pre- and post-COVID comparisons  

4. **Geospatial Analysis**
   - Crash distribution across NYC boroughs  
   - Location-based insights  

5. **Self-Guided Research Question**
   - Evaluated whether COVID-19 had a lasting impact on accident patterns  

---

## Key Insights
- Crash patterns remained **largely consistent over time**, including before and after the COVID-19 pandemic.
- Peak accident times stayed **stable across years**, particularly during commuting hours.
- Despite changes in traffic volume during COVID-19, **overall accident trends did not significantly shift**.
